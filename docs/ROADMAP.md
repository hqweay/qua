# 路线图

> 这份只写**接下来做什么、按什么顺序**。已做成的能力在 [`../README.md`](../README.md)「能做什么」，
> 每条约束**为什么存在**在 [`ARCH-断言.md`](ARCH-断言.md) 与 [`模型-一切皆块.md`](模型-一切皆块.md)。

当前阶段：**beta**（桌面安装包从 0.1.0-beta.1 起挂 Releases）。输入面形状与三张表已钉死，
桌面端真实存储（SQLite 行存储、多库、全文检索）已落地；这份只列还没做的。

---

## 0 判断优先级的两条尺子

排在做与不做之间的，不是「谁先想起来的」，而是这两条：

1. **它会不会让输入面的形状退化？** 会 ⇒ 最高优先级。
   （输入面形状 = 块树 ＋ 块内 run 序列 ＋ IME 组合不出错）
2. **它是不是「一次换实现、上层不改」的接缝？** 是 ⇒ 值得提前铺，因为它决定后面所有能力长什么样。
   （例：持久化的 `StoragePort`、渲染的 `renderBlock`、命令的声明表）

反过来，**看起来紧急但可以后置**的：界面细节、皮肤、动画、导入导出格式、多端。

## 1 现在这一格：数据出得去

「写下来之后还要反复使用」的下限是**内容能完整离开这个应用**：一旦哪次格式升级没保住数据，
用户手上至少还有一份能带走的文件。这也是「重放等于状态」的第一个真实出口。

### 1.1 导出 / 备份文件（未做）

**现状**：读盘失败会进只读态（不覆盖）；开发构建的调试菜单已有「备份并重建本地库」——
原始字节先抄到 `qua.workspace.bak.<时刻>`，备份失败就中止覆盖；换数据格式前桌面版会自动
在库目录 `backups/` 留一份整库快照。**还缺**：用户面的「把当前库导出成文件」出口。

**要做**：JSON（块 ＋ 属性 ＋ 资产清单）＋ `assets/` 字节的一份打包，round-trip 进门禁
（导出的库重新导入后与导出前逐块相等）。顺手拍三个小口径：快照是否打包资产字节、
恢复后全文索引回 `pending` 重建、资产回收与导出文件的关系。

### 1.2 Markdown 导出（口径已定，未实现）

单向投影，不是 round-trip：页／日记一文件，页标题 `#`，内容按嵌套列表投影，
子页单独成文件并以链接相连；代码块按围栏、引述按引用块投影，自定义语气在文件里降级成普通引述。
**不做**「缩进深度 → 标题层级」。JSON 才是往返格式，Markdown 是给人看的。

## 2 壳与发布

- **签名与公证**（现在 `.app` 未签名，换机器会被 Gatekeeper 拦；Windows 同理）
- **自动更新** ✅ **已落地（0.1.0-beta.9 起）**：通知 ＋ 应用内下载——每 5 小时查一次发布源，
  有新版菜单换成「有新版 X…」；点开可把本平台的安装包下载到「下载」文件夹并打开，
  下载中 Dock／任务栏显示进度，最后一步安装由用户完成。
  **还缺**：**后台下载→重启即完成仍要等签名**——macOS 上那一步由系统组件完成，
  它判断「新包是不是我发的」只看代码签名，未签名的包装不进去。
- **CSP 收紧**（现在 `default-src 'self'` 够用，但还没逐项审）
- **深色跟随系统**在真机上复核一次

## 3 输入面与大文档的余项

| 项 | 现状 | 要做 |
|---|---|---|
| **跨块编辑的边界** | 同一父块下的跨块选区可以直接删改（首尾两段拼成一块）；跨父块、或首块是段根（页／日记正文第一层）时仍不支持 | 把这两类边界补上 |
| **虚拟化的默认档** | 已窗口化挂载，行高按实测缓存；开关仍默认关。日记流／多段文档还有两处估高缺口（段间留白、折行长块） | 先补段边界与折行估高，再谈默认打开 |
| **装载形状** | 启动仍把整片森林读进内存 | 按 id／按页的局部装载，等查询与反链也走 SQL |
| **行内语义尺寸** | 没有「同一行里放大／缩小几个字」的格式位 | 等真实需求（导出／打印逐段保真）再立项 |

## 4 明确**不做**（至少现在）

| 不做 | 为什么 |
|---|---|
| 换掉 Electron | 壳已经做到「主进程不含业务」，换壳收益低于成本 |
| 引入前端框架 | 编辑器 DOM 是自研的，引框架只会多一层需要对抗的抽象 |
| 皮肤 / 主题市场 | 主题只填 `--ui-*` 的机制已经在了，等真正有第三方需求再说 |
| 兼容旧落盘格式 | 原型阶段 `WORKSPACE_VERSION` 加一即作废，写迁移是纯负债 |
| 移动端 | 要等「事务 + 同步」落地之后；现在做只能做出一个分叉的模型 |
| 云同步 / 插件 / AI | 只保接缝：写入走 op 流、视图配置可序列化、命令面是唯一入口 |
