# 相（Qua）

**一个以「块」为唯一原子的笔记应用。**

你写下的每一段内容都是一块。页、日记、标签、视图、面板——它们不是几样东西，
是同一批块在不同位置、不同看法下的样子。所以任何一块都能换个名字、换个地方、
换种看法再出现一次，而它始终是同一块：改一处，处处同步。

## 试用

**在线演示（最省事）**：[qua.leay.net](https://qua.leay.net/) —— 不用安装，打开就能写。
数据只存在你自己浏览器里，不上传任何服务器；清掉浏览器数据＝数据没了。

**桌面版（macOS，功能完整：SQLite 存储 ＋ 全文搜索）**：

```bash
git clone https://github.com/hqweay/qua.git
cd qua && pnpm install
pnpm build:mac        # 产物在 release/ 下的 .app
```

`.app` 目前**没有签名**：首次打开如果被拦，右键 →「打开」，或在系统设置里放行。

### 这是 beta，先把丑话说完

1. **升级可能作废旧库，且不做迁移。** 数据口径变化时我们直接换口径、版本号加一，
   旧数据显式作废。桌面版请定期**把库目录整个拷走一份**（见「数据放在哪」）；
   演示站的数据在版本更新后可能清空重来。
2. **没有导入导出、没有云同步、没有自动备份。** 数据只在你自己的机器上。
3. **界面只有中文。**
4. 遇到 bug 或数据异常，请去 [Issues](https://github.com/hqweay/qua/issues) 报告，
   最好带上「做了什么操作」与「库目录大小／时间」这类现场信息。

## 一个主张

> **库里只有一个东西：块。别的东西都是它的打扮。**

| 你以为是实体的 | 它其实是 |
|---|---|
| 页 | 一块有名字、有描述的内容，登记进了页列表 |
| 日记 | 一块带着日期；全局一天一个，今日永远在顶 |
| 标签 | 一个块；「打标签」是把另一块归进它 |
| 视图 | 对真实内容树的一次渲染，不是一份新数据 |
| 侧栏 / 面板 | 一个槽，里面摆着一列块 |

这个主张推出四条贯穿全产品的判据：

1. **名字属于身份，位置属于内容。** 一个块在哪儿、出现在几处，不改变它是谁。
2. **格式随文字走。** 正文不是一坨带标记的 HTML，是一串不可再拆的行内单元——
   删一个引用、一张图片，不会伤到旁边的字。
3. **数据只回答「是什么」，「怎么显示」归视图。** 同一批内容，换一种看法不用重排数据。
4. **渲染只认块自己，不认它在哪个容器里。** 所以一个块可以在多处同时出现、同时被编辑。

完整推导与已否决方案在 [`docs/模型-一切皆块.md`](docs/模型-一切皆块.md)——想动模型先读它。

## 写：一块一块地长出来

正文是一棵可编辑的块树。光标落在哪，`Enter` 就按那个落点建块：块中拆成同级、
块尾建子块、空块深处反缩进。缩进、折叠、拖拽重排都在这棵树里完成，子树跟着走。

一段文字可以自带四种格式（**加粗**、*斜体*、高亮、`行内代码`）。
`[[引用]]`、`#标签`、`@提及`、外链、行内图片都是**原子**：不可再拆，删它们不伤邻居。

打字键一个都没绑——所有快捷键都是「绑定到命令」的，没绑上的键一律正常输入文字；
输入法组合期间所有快捷键自动不命中，不会打断你打中文。

`/` 斜杠菜单、`⌘P` 命令面板、块标右键菜单——三个入口回答三个不同的问题，共享同一张命令表。
命令与键位都是数据：改一个键位不用改任何事件分支，`⌘⇧?` 随时看全部键位。

![命令面板：列全部命令、可搜、无绑定也能执行——键盘可达性的兜底](shots/overlay-命令面板.png)

![正文里的斜杠菜单：行首或空白之后敲 /，就地插入块、日期、引用、图片](shots/overlay-斜杠菜单.png)

## 组织：页、日记、标签，都是块

- **日记**：随手记录落在今天；日记流今日在顶，更早的天往下。`⌘⇧R` / `⌘⌥⇧R` 复盘最近 3 / 7 天。
- **页**：`⌘⇧N` 新建独立页；`@` 提及页与块（同一张候选表），没有同名页时当场建页并引用。
- **标签**：敲 `#名` 默认只是**提及**，`⌥↵` 才是把这一块**归进去**。标签有层级，
  查父标签能看到子标签的块。
- **归属**：任何块都能配「属于」，左槽的归属树按页 / 标签两面摊开。
  拖一块到归属树的一行＝加一条「属于」边，**不是搬家**——一块可以有多个归属。

![一页的正文：页头别名、行内引用与图片、四种区间格式、待办、标签 chip、页底查询与引用](shots/readme-page.png)

## 看：同一批内容，七种看法

一个查询决定**哪些块进来**，一个看法决定**怎么画**。换成另一种看法**不重查**——
条件相同、数据相同，结果就相同。

| 看法 | 一行是什么 |
|---|---|
| **大纲**（缺省） | 缩进树本身；点文字就能改 |
| **表格** | 行＝记录，列＝属性；格子里直接改 |
| **大纲表格** | 表头＝直接子块，一列＝那个子块的孩子 |
| **卡片** | 一张卡＝一块（正文＋属性行），点卡里就能改；默认排成网格（画廊），选一个分组列就排成列（看板），拖卡＝写那一格的值 |
| **日历** | 月网格，今天有描边，没有日期的条目列在下方 |
| **思维导图** | 只接子树，节点上限 500，超了明说 |
| **页签** | 页签＝直接子块，页内是那一块的子树 |

![表格视图：同一个查询，行是记录、列是属性，格子里能直接改](shots/view-表格.png)

![看板视图：同一批记录按一列分组，拖卡写值、不换父子](shots/view-看板.png)

### 查：把条件读成一句话

查询条件是一棵**条件树**：一行一条，读成一句话；`全部满足 / 任一满足` ＋ 每层一个「非」，可嵌套。
算子覆盖 等于 / 包含 / 大于 / 小于 / 有没有值 / 是不是空——「未填的任务」和「不是任务」是两件事，分开表达。

![条件树：条件按行展开，读成一句话；点「应用」才写一次](shots/query-条件树.png)

## 同一块，多处出现

三种方式让同一份内容在别处再出现一次，**一处编辑、多处同步**；关闭视图不删块：

- **露面（镜像）**：把一页或一个块摆进另一页的正文里。空心块标说的是
  「这一行的身体不是一份独立内容」。
- **侧槽窗口**：拖一个块进左槽或右槽，得到一张钉住的窗口卡，卡里是同一份内容，能直接改。
- **查询**：一组条件可以被正文、侧槽、整屏页面同时渲染，各自冻结自己那一份结果。

![露面：把「产品设计」页以大纲表格摆进另一页的正文里，空心块标表示它是投影](shots/embed-大纲表格.png)

![侧槽窗口：右槽是一列卡（窗口、检视、反链、回收站），窗口卡里同一块可直接编辑](shots/dock-窗口卡.png)

## 属性：一块的数据，写在它自己身上

字段是全局定义的块，值写在每块自己身上，右槽的检视卡按当前对象画。

- 按字段类型提供 文本 / 数字 / 日期 / 勾选 / 单选 / 引用 / 链接 的编辑面。
- 高频属性在块左侧有一个快捷入口：画当前值的图标，点它开取值菜单；面板与行上改的是同一个值。
- 把一个单选字段标成「任务状态」后，勾选即完成——自定义的任务属性和内置待办走同一套
  勾选、删除线与查询。勾上「允许多个值」，一块可以选多个选项。
- 日期、创建 / 修改时刻是块自己的事实，只读展示。

## 交互速查

| 键 | 做什么 |
|---|---|
| `Enter` / `Backspace` | 按落点建块：块中＝同级拆；块尾＝子块；空块深层＝反缩进。块首退格＝合并到前一块 |
| `Tab` / `Shift+Tab` | 缩进 / 取消缩进 |
| `⌘⇧↑` / `⌘⇧↓` | 上移 / 下移当前块 |
| `⌘A` | 全选正文（跨块）；`⌘⇧A` 开始块选区，`⇧↑`/`⇧↓` 扩选 |
| `⌘.` | 折叠 / 展开当前块 |
| `⌘⏎` | 切换待办 |
| `⌘⇧D` | 删除块；块选区激活时＝删除所选块 |
| `⌘B` `⌘I` `⌘E` `` ⌘` `` `⌘⇧M` | 加粗 / 斜体 / 高亮 / 行内代码 / 清格式 |
| `⌘C` `⌘X` `⌘V` | 块上复制（贴回得引用）；块选区剪切 / 粘贴＝移动；`⌘⇧V` 粘贴为镜像；划选 `⌘⇧C` 复制锚文本引用 |
| `⌘⇧K` / `⌘K` | 插入 `[[引用]]` / 外链（只收 `http`、`https`） |
| `/` 或 `⌘/` | 斜杠菜单 |
| `⌘P` | 命令面板（无绑定也能执行） |
| `⌘K`（正文失焦时） | 全文搜索（桌面端走 SQLite 全文索引） |
| `#` / `@` | 标签浮层（`⌥↵` 归类）/ 提及页或块 |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做（按事务记动过的块，含结构与行内内容） |
| `⌘[` / `⌘]` | 后退 / 前进（与撤销是两套） |
| `⌘T` | 回今日；`⌘⇧[` `⌘⇧]` `⌘⇧W` 切换 / 关闭页签 |
| `⌘⌥←` / `⌘⌥→` | 上一天 / 下一天（日记视图） |
| `⌘⌥1` / `⌘⌥2` | 开关左槽 / 右槽 |
| `⌘⇧L` / `⌘,` | 亮 / 暗 / 跟随系统 ／ 设置 |
| `⌘⇧?` | 键位表（按生效值报，永远和实际一致） |

**鼠标**：悬停块左侧出现块标。**左键 ＝ 聚焦**，**右键 ＝ 块菜单**，拖动 ＝ 重排。
**Shift+左键**任何可打开的地方＝在右槽开一个窗口；`⌘/Ctrl+左键`＝新页签；`⌥+左键`＝就地看属性与详情。
拖拽落点：落到正文＝移动；落到归属树＝加一条「属于」边；落到侧槽＝在那一槽打开。

## 数据放在哪

**桌面版**：每个库是「文稿/Qua」下的一个目录：

```
<库目录>/
├── library.json   库的身份
├── qua.db         SQLite：全部内容的真相
├── assets/        图片按内容哈希存字节
└── backups/
```

内容不是一大坨 JSON：每块是自己的行，**一次编辑只写它动过的那几块**，写盘成本不随库体量增长。
全文搜索走 SQLite 的全文索引表，可在设置里全量重建。

**浏览器（演示站）**：没有「用户可选目录」的语义，数据在浏览器的 localStorage 里。

**删除是软删**：删掉的块进右槽的回收站卡，可以一键恢复；
恢复后名字、属性、被谁引用的关系都还在——同一个身份不会分裂成两块。

## beta 已知边界

- 没有导入导出（Markdown／OPML／JSON 都还没有）。数据进出目前只有「在这个应用里写」一条路。
- 桌面壳未签名公证、没有自动更新；升级＝重新构建，**升级前先备份库目录**。
- 跨块**文本选区**的删除 / 替换还没实现（块级的多选删除 / 复制可以）。
- 视图配置还差列宽拖动、日历的日期列选择。
- 行内资产只有图片；删掉一张图片的引用，字节暂不回收。
- `#` / `@` 浮层的候选仍只扫内存里的名字，没接全文索引。
- 没有移动端、没有协作、没有插件系统——这些都要等同步与事务基建，不是现在的目标。

### 架构一眼

```
core ← view ← ui ← app ← host
```

- **`core/`** —— 零 DOM。模型、纯逻辑、命令声明、消息字典。
- **`view/`** —— 编辑器 DOM 契约与事件。不许 import `ui`。
- **`ui/`** —— 组件。只认语义 token，不认基础色。
- **`app/`** —— 命令实现。命令只经门面改状态，不碰 `document`。
- **`host/`** —— 装配与 Electron 壳。只做 wiring。

结构约束由 `pnpm arch:check` 静态执行（三十余条硬断言，不是约定），
逐条账在 [`docs/ARCH-断言.md`](docs/ARCH-断言.md)；分层与字段的可视化在
[`public/arch.html`](public/arch.html)（线上版 [/arch.html](https://qua.leay.net/arch.html)）。
