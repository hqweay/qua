# 相（Qua）

**块级大纲笔记 · 桌面版。** 一个以「**块**」为唯一一等公民的桌面笔记：
页、日记、标签、视图、侧栏，都不是独立实体，而是块在不同位置的不同呈现。

![相 / Qua——块级大纲笔记的桌面界面：左槽是归属树与今日，正文是块树，右槽是检视卡与反链；页底是查询结果与反向链接](shots/readme-hero.png)

**[在线演示 → qua.leay.net](https://qua.leay.net/)** · 不用安装，打开就能写；
数据只落在你自己的浏览器里（`localStorage`），首次打开会载入一份假数据库。
想先看设计再看产品：**[架构与数据结构 → /arch.html](https://qua.leay.net/arch.html)**，
一张图讲清分层、块的字段、写/读路径 —— 图上的版本号与门禁基线由部署流水线现算，不是手写的。

> ⚠️ **这是原型，不是 v1。** 不接数据库、不接内核进程、允许硬编码假数据。
> 当前阶段唯一不许退化的两样东西：**输入面的形状**（块树 ＋ 块内 run 序列 ＋ 稳定块 id）
> 和**三张表**（命令 / 绑定 / 上下文键）。

## 名字：相 与 Qua

| | 用在哪 | 说明 |
|---|---|---|
| **相** | 显示名 | 应用名、窗口标题、菜单栏、安装后的 App 名。`productName: "相"` |
| **Qua** | 工程名 | 仓库名、包名、命令、文档里指代这个项目。**相是 Qua，Qua 是相**，两个名字指同一个东西 |
| `net.leay.qua` | 标识符 | `appId` / `bundleId`。用全小写 ASCII，**不含中文也不用连字符**——它决定用户数据目录的路径（`~/Library/Application Support/net.leay.qua/`），中文路径在脚本、日志、备份工具里到处是坑 |

起草理由：「相」＝ 看见的那个面（视角即本体）；「Qua」取 *qua*（作为／就其为）——
同一个东西，换个位置就是另一种看法。这是产品的核心主张，不是随手起的名字。

> 命名**不可逆**：改 `appId` 会让所有人的数据目录搬家。真要改，必须配迁移。

## 它想验证什么

笔记工具的内核只该有**一块**：块。在此之上有四条判据，代码是围着它们长的。

| 判据 | 在代码里的落点 |
|---|---|
| **输入面形状优先**：正文用自研块级 DOM（不是 contenteditable 套 ProseMirror），内容是一串 run、原子不可分，IME 组合期不重渲染正在组合的块 | `src/view/` · `src/core/runs.ts` |
| **三张表说了算**：命令（纯语义）、绑定（键位/菜单/斜杠/工具栏/命令面板共用一张）、上下文键（开放键空间，IME `composing` 也是一个键） | `src/core/commands/` · `bindings.ts` · `when.ts` |
| **主进程不含业务逻辑**：壳只做窗口与端口中转；换内核时 renderer 一行不用改 | `electron/main.ts`（只有五件事） |
| **换肤不改 DOM 形状**：主题只换 token，冒烟断言钉死「换肤前后 `data-depth` 序列一致」 | `src/styles/tokens.css` |

「一切皆块」这条模型铁律的完整推导在 [`docs/模型-一切皆块.md`](docs/模型-一切皆块.md)——
**动模型之前先读它**，那里也列了「别再想一遍」的已否决方案。

## 快速开始

不想装环境？先开 **[在线演示](https://qua.leay.net/)**——同一份前端构建（产品构建，不含开发工具入口），
数据存在你自己浏览器的 `localStorage` 里，不会碰到别人的库。

本地跑：

```bash
git clone <this-repo> && cd qua
pnpm i
pnpm dev          # vite + electron 一起起；光标已在第一块，直接敲字
```

不需要配置任何东西。打开就能写；关掉重开内容还在（数据落在 Electron 的 `localStorage`）。
首次启动且本地无数据时，会载入一份像真实笔记的假数据库。

| 前置 | 版本 | 说明 |
|---|---|---|
| Node | **26.x** | `package.json` 的 `engines` ＋ `.node-version` 都钉住了。旧版会让 rollup 原生模块 dlopen 失败 |
| pnpm | 11.x | `packageManager` 字段钉住 |

只想起浏览器版（不启 Electron）：

```bash
pnpm dev:web      # → http://127.0.0.1:5180/
```

## 交互一览

**键盘**

| 键 | 做什么 |
|---|---|
| `Enter` | 按落点建块：块中＝同级拆；块尾＝子块（无子块/折叠时＝同级）；空块深层＝反缩进 |
| `Backspace` | 块首 ⇒ 合并到前一块；否则原生删除 |
| `Tab` / `Shift+Tab` | 缩进 / 取消缩进 |
| `⌘A` | 全选正文（跨块） |
| `⌘⇧A` | 开始块选区；`⇧↑` / `⇧↓` 扩选，`⌫` / `Delete` 删除所选，`Esc` 取消 |
| `⌘.` | 折叠 / 展开当前块 |
| `⌘⏎` | 切换待办 |
| `⌘⇧D` | 复制块（含子树）；**编辑器失焦时**＝回今日 |
| `⌘⇧⌫` | 删除块 |
| `⌘B` `⌘I` `⌘E` `` ⌘` `` | 加粗 / 斜体 / 高亮 / 行内代码（格式是**那一截文字自己的属性**，随文字走） |
| `⌘P` / `⌘⇧P` | 命令面板（列全部命令、可搜、**无绑定也能执行**——这是键盘可达性的兜底） |
| `/` | 斜杠菜单（行首或空白之后）；`⌘/` 随时打开 |
| `#` | 标签浮层：`↵` 插入一枚**提及** · `⌥↵` 把标签**归到本块** · `⇧↵` 新建一条落在今天的**实例**（没有同名标签时，`↵` 建标签并引用、`⌥↵` 建标签并归类、`⇧↵` 建标签并新实例） |
| `@` | 提及页或块（页与块同一张候选表）；没有同名页时 `↵` 当场建页并引用 |
| `⌘⇧K` | 插入 `[[引用]]` |
| `⌘⇧N` | 新建页（独立页，住森林顶层） |
| `⌘⇧L` | 亮 / 暗 / 跟随系统 切换 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做（模型快照栈，含块结构与行内内容） |
| `⌘[` / `⌘]` | 后退 / 前进（中心槽的导航历史；与撤销是两套） |
| `⌘⇧R` / `⌘⌥⇧R` | 复盘：最近 3 天 / 最近 7 天 |
| `⌘⌥←` / `⌘⌥→` | 上一天 / 下一天（仅在日记视图且编辑器失焦时） |
| `⌘⌥1` / `⌘⌥2` | 开关左槽 / 右槽 |
| `⌘⇧?` | 键位表 |
| `⌘⇧V` | 虚拟化开关（user 层绑定：演示「加一条键位不改核心」） |

打字键一个都没绑（未绑定 ⇒ 文本输入）；IME 组合期所有键位自动不命中。

**鼠标**：悬停块左侧出现块标；**左键 ＝ 聚焦/zoom 到这块**，**右键 ＝ 块菜单**，拖动 ＝ 重排。
**Shift+左键任何「可打开」的地方**（块标、行、行内引用、反链、面包屑、归属树的一行）＝ **在右槽打开一个窗口**；
它不换中心、不记历史；再点只定位、不关闭，**关闭走窗口卡头的 ×**。
块前的导轨画的是祖先层级，**点某一段就折叠那一层祖先的子块**（再点展开）。
拖一个块到**归属树的一行**上 ＝ 给这两个块加一条「属于」边（不是把块搬走）；落到正文 ＝ 移动；
落到侧槽 ＝ 在那一槽打开。落点含义在悬停时就写在拖拽提示里。

**侧槽**：**一个块一张卡**（窗口）——把块从正文拖进左槽或右槽 = 在那一槽打开；
左槽默认是**归属树 ＋ Daily note**，右槽默认是**检视卡 ＋ 反链**。
卡头可以**收起**、**只看这一张**、**拖拽排序**（含左槽拖到右槽）。
卡片里是同一份块，可直接编辑；关闭只影响视图，不删块。
拖左右槽的内侧边缘 = 调整宽度，双击手柄 = 恢复默认。

## 现在能做什么 / 还不做什么

**能**：

- **输入面**：块树编辑 · Enter 按落点建块 · 区间格式 · 行内引用与图片 · 待办 · 折叠 ·
  拖拽重排 · 块选区（`⌘⇧A` 后整块删除、复制、复制引用）。
- **点开一处露面**：凡是「指向某块」的东西——正文里的 `[[名]]`／`#名`、行尾标签 chip、
  属性区的标签名、侧槽窗口里的引用——**点名字都打开它**：左键进中心、`Shift`+左键开右槽、
  `⌥` 看详情（只有行内引用有详情；chip 只有归属）。
- **命令与检索**：命令面板与斜杠菜单 · `#` 的三个落点（提及 / 归类 / 新建实例）·
  `@` 提及页与块 · 命令/绑定可以只在数据里加就生效。
- **日记与复盘**：`#` 新建的实例与随手记录**落在今天**；新建页是独立页（住森林顶层），
  `@` 无同名页时也能当场建页并引用；日记流今日在顶、更早存在的天往下；
  复盘 3 / 7 天（窗口里没写过的天显示空壳，落笔才物化）；上一天 / 下一天。
- **块的身份**：**标签＝块上的一格分类**（`props._tags`，成员按归属派生，不占正文、渲染成行尾 chip；
  正文里敲 `#名` 默认只是提及，`⌥↵` 才是把这块归进去）· **标签层级**（属于/包含；查父标签能看到
  子标签的块，但字段不跟着继承）· **别名与露面**（名字住在 `props._aliases`：首个是主名、可多名、
  允许 `/` 分段；正文（`content` 的文本投影）是描述；行头的别名编辑器可以加/删名字、设主名、
  勾选「页列表 / 标签列表」、切换这一行显示别名还是文本）· **列表露面**（任意块可兼作页/标签：
  块菜单加/减露面；页不再要求顶层）· **归属**（`props._belongsTo`：任何块都能配「属于」，
  左槽的归属树按页/标签两面摊开，拖入＝加边，不是搬家）· **提取为页**（块菜单 / 命令面板：
  标记为页 ＋ 把块连子树搬到森林顶层 ＋ 在原位置留一枚引用；原 id 与所有引用不变）。
- **属性**：全局字段定义、平铺 ＋ 来源标注；按 kind 提供文本 / 数字 / 日期 / 勾选 / 单选 / 引用 /
  链接的编辑面；画在**右槽的检视卡**上，跟着当前对象走；另有一段只读的**系统信息**（创建 / 修改时刻）。
  高频属性（如任务状态）在块左侧另有一个**快捷入口**（勾选框），两处改的是同一个值；
  页/标签的卡里多一段「声明给成员」（列出为成员声明的属性，可解除，并有**自己的**添加入口）。
  **两个添加入口写的是两个不同的东西**：卡片抬头「＋ 属性」＝这一块自己的值；
  声明段「＋ 声明属性」＝成员的属性格。标签块因此既能给自己加属性，又能给成员声明属性。
- **视图与槽**：查询视图（冻结结果集 ＋ 刷新按钮 ＋ 原地编辑；条件覆盖标签 / 待办 / 属性 / 引用 /
  某一天，结果可排序）· 反链 footer 与右槽反链卡（共享 block store，正文与反链同一块不打架）·
  结果／反链最外层行的**行首面包屑**（沿父链取；普通点就地展开上下文，`⌘/Ctrl` 点跳转、
  `Shift` 点右栏；展开根可逐层收起）·
  左右槽打开真实块的窗口并原地编辑 · 卡片收起/单卡/拖序/跨槽 · 槽宽拖拽 ·
  导航前进/后退 · 亮暗/跟随系统 · 虚拟化（窗口化挂载）。

**还不能**（原型边界）：

- **持久化仍是整库序列化**：每次提交把整库（或整批）JSON 序列化进 localStorage；
  模型层有 `tx`／`Op` 事务语义，但没有数据库事务、没有多窗口同步。
- **没有备份/导出入口**：读盘失败时进入只读演示态（不覆盖原数据），但用户暂时没法抢救坏库。
- 没有自研查找（`⌘F`）、没有全文搜索（`#`／`@` 浮层只扫内存里的名字与正文，不是全文索引）、
  没有图谱、没有导入导出；界面文案只有中文（走字典，但没有多语言切换）。
- 块选区可以整块删除/复制；但**跨块文本选区**的删除/替换还没在模型侧实现。
- 标签页的成员 footer 可原地编辑，但成员顺序还不能手动调。
- 属性值的编辑面已覆盖全部 kind（`ref` 有块选择器）；只有 `select` 的**选项目录**还没有编辑 UI；
  字段定义块不进任何列表（按 `_kind` 过滤，未来由字段管理视图接）。
- 引用目标被删时显示插入时的旧名（dangling）；这是少数派状态的兜底，不假装解析成功。
- 桌面壳未签名公证、没有自动更新、深色未在真机验证跟随系统。

每一条的现状与取舍在 [`docs/ARCH-断言.md`](docs/ARCH-断言.md) 与
[`docs/ELECTRON-备忘.md`](docs/ELECTRON-备忘.md) 里都有对应段落。

## 架构一眼

```
core ← view ← ui ← app ← host
```

- **`core/`** —— 零 DOM。模型、纯逻辑、命令声明、消息字典。
- **`view/`** —— 编辑器 DOM 契约的产地（块级 DOM、run 渲染与读回、事件）。**不许 import `ui`**。
- **`ui/`** —— 组件（槽、浮层、角标…）。只认 token，不认基础色。
- **`app/`** —— `App` 门面与命令实现。命令只经门面改状态，**不碰 `document`**。
- **`host/`** —— `src/main.ts` 的装配 ＋ `electron/` 的壳。只做 wiring。

结构约束由 `pnpm arch-check` 静态执行（当前 **19 条硬断言**，不是约定）。几条有代表性的：

1. 层级只能单向依赖，`view` 不得 import `ui`；
2. 命令 handler 不得出现 `document`／`window`；
3. 用户可见文案不得是裸中文，一律 `t('id')` 走 `core/msg.ts` 字典；
4. 组件不得引用基础色 `--c-*`，只能用语义槽 `--ui-*`；
5. 块树遍历只有一个入口（`core/walk.ts` 的 `walkForest`），不许自己递归 `children`；
6. 行内内容只有 run 序列一套，旧形状的零件不许复活。

逐条账（哪条真在跑、哪条只能靠约定、哪条等内核）在 [`docs/ARCH-断言.md`](docs/ARCH-断言.md)。

## 命令

```bash
pnpm dev             # 开发：vite + electron（src/** 热更新；electron/*.ts 改动要重跑）
pnpm dev:web         # 只起 vite → http://127.0.0.1:5180/
pnpm gate            # ★ 唯一门禁（全量）：静态 + 单测 + 构建 + 冒烟 + 布局 + 真 Electron
pnpm gate:web        # 同 gate，但不含 Electron（公开仓 CI 的 Linux job 用它）
pnpm gate:fast       # 日常小改动：按 git 改动只跑「碰得到的那几支」（不是收工门禁）
pnpm arch:check      # 只跑架构静态断言（秒级）
pnpm test:core       # 只跑纯 core 单测（node --test，零依赖）
pnpm check           # 浏览器级冒烟（真 Chrome、真按键、真鼠标）
pnpm check:smoke     # 只跑浏览器冒烟，不重建 dist
pnpm check:dock      # 槽与排版形状的布局断言（真量尺寸）
pnpm check:electron  # 真 Electron 冒烟
pnpm check:bundle    # 打包产物冒烟（要现有 .app，慢，单列）
pnpm gate:bundle     # gate + 打包产物冒烟
pnpm shots           # 截图 ⇒ shots/
pnpm build:mac       # 打包 .app（未签名，首次需右键打开）
```

**改完必须 `pnpm gate` 全绿才算收工。** 它按产物依赖分三段、**段内并发**跑：

```
① 静态与单测   typecheck · arch:check · test:core
② 构建         build:test · build:electron
③ 冒烟         check（用例切片并发）· check:dock · check:electron
```

> 快的原因**是并发，不是少跑**——断言一条没动。冒烟的用例本就互相独立（每条自己开一个干净
> 上下文），所以按序切片分给几个进程；合并端会验「各片看到的用例数一致、合并后条数等于它」，
> 因为分片唯一能悄悄失效的地方就是**漏掉某条用例而它不报错**。

> `build:electron` 是门禁必需的一环——少了它，`check:electron` 会拿旧的 `main.cjs`
> 跑出**假绿**（真踩过，所以写进门禁而不是写进文档）。

> **`pnpm gate:fast` 不是收工门禁。** 它按这次变动的路径判面（core／web／electron／文档），
> 跳过碰不到的，并把跳过了什么逐条打出来；认不出的路径一律按全量。
> 只想看它判定结果：`pnpm gate:fast --plan`。

## 数据放在哪

`localStorage` 的键是 **`qua.workspace`**（`src/core/workspace.ts`）。
在 Electron 里它落在 `~/Library/Application Support/net.leay.qua/Local Storage/`。

⚠️ **改这个键名＝所有用户的数据静默消失**，所以 `arch-check` 有一条断言把值钉死。

落盘形状的版本号是 `WORKSPACE_VERSION`（`src/core/storage/shape.ts`）。原型**不做旧数据迁移**：
模型或落盘口径一变就把版本号加一，旧库显式作废、重新 seed，不写兼容分支。
在浏览器（含[在线演示](https://qua.leay.net/)）里，同一份键落在那个站点的 `localStorage` 中。

数据目录的整体形状（`kb/` `logs/` `cache/` …）见 [`electron/userdata/README.md`](electron/userdata/README.md)。

**先读 [`AGENTS.md`](AGENTS.md)** —— 那份是动手前必须知道的工程纪律（AI agent 也会自动加载它）。

- 打算动手？先看 [`docs/ROADMAP.md`](docs/ROADMAP.md) —— 现在该做什么、每条怎么算做完。
- 分支与提交：见 [`CONTRIBUTING.md`](CONTRIBUTING.md)。
- 设计上的取舍：`docs/` 下几份是「为什么长这样」，代码注释只写「为什么」，不写「改了什么」。

## 文档地图

| 文档 | 给谁看 | 内容 |
|---|---|---|
| `AGENTS.md` | 贡献者 / AI agent | 铁律、门禁、代码纪律速查 |
| `CONTRIBUTING.md` | 贡献者 | 分支、提交、PR、review 口径 |
| `docs/ROADMAP.md` | 想动手的人 | 接下来做什么、按什么顺序、怎么验收 |
| `docs/模型-一切皆块.md` | 改模型的人 | 模型第一性、三条判据、已否决清单 |
| `docs/ARCH-断言.md` | 贡献者 | 架构断言逐条账：能静态查的 / 只能靠约定的 / 等内核的 |
| [`public/arch.html`](public/arch.html) | 所有人 | 一张图的架构与数据结构（部署时填真值 ⇒ 线上版 [/arch.html](https://qua.leay.net/arch.html)） |
| `docs/ELECTRON-备忘.md` | 改壳的人 | 桌面壳踩坑、与 Chrome 的行为差异、真机实测 |
| `TODO.md` | 贡献者 | 已知 bug 与概念澄清（QB 编号、复现步骤、状态） |
| `electron/userdata/` | 发布/排障 | 运行时数据目录的形状 |
