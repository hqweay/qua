# 相（Qua）

一款桌面大纲笔记，为「写下来之后还要反复使用」而设计。

在相里，你写的每一行都是一个可独立操作的单位：可以打标签、加属性、被引用到任何地方、
拖进表格或看板重新排列、镜像到多个页面。改动任何一处，所有出现它的地方同步更新——
内容不会被锁死在写下它的那个页面里。

![相 / Qua 的默认界面：正文是一棵可编辑的块树，两侧是可开关的侧槽](shots/readme-hero.png)

## 快速开始

**在线体验**：[qua.leay.net](https://qua.leay.net/) —— 打开就能写，不用安装。
数据保存在你自己的浏览器里，不会上传到任何服务器。

**macOS 桌面版**（SQLite 存储、全文搜索，功能更完整）：

```bash
git clone https://github.com/hqweay/qua.git
cd qua && pnpm install
pnpm build:mac
```

生成的 `.app` 尚未签名，首次打开若被系统拦下，右键 →「打开」即可。

### 关于 beta

相还处在 beta 阶段，有几件事想先说清楚：

- **升级版本时旧数据可能无法保留。** 数据格式变化时我们选择直接换新格式，
  而不是写迁移。如果你在用桌面版，升级前请把库目录整个拷贝一份作为备份。
- **暂时没有导入导出和云同步**，数据只在你自己的电脑（或浏览器）里。
- 界面目前只有中文。
- 有任何问题都欢迎到 [Issues](https://github.com/hqweay/qua/issues) 告诉我们。

## 它特别在哪

页、日记、标签、视图之间没有僵硬的边界：一篇页可以同时是某个标签的成员、
同时出现在三个查询结果里、被引用进另一篇页——这些都是同一份内容的不同用法，
不是三份拷贝。几个具体的性质：

- **一块内容，多处出现。** 镜像到另一页、钉进侧槽窗口、被查询捞出来——都是同一块，
  在哪里都能直接编辑，改动处处同步。
- **删除是可恢复的。** 删掉的块进回收站，恢复后名字、属性、被谁引用的关系都原样回来。
- **看法与数据分离。** 同一批内容可以从大纲、表格、看板、日历等不同角度去看，
  换看法不重排数据，改看法也不动你的内容。

这个设计背后的模型（页、日记、标签、视图为何都能还原成块）写在
[`docs/模型-一切皆块.md`](docs/模型-一切皆块.md)，感兴趣再读，不读不影响使用。

## 能做什么

**写**：正文是一棵可编辑的块树，`Enter` 按光标落点智能建块（块中拆分、块尾建子块）。
加粗、斜体、高亮、行内代码随文字走；`[[引用]]`、`#标签`、`@提及`、外链、图片都是
完整的行内单元，增删不会伤到旁边的字。输入法组合期间快捷键自动让路，中文输入不受干扰。

**组织**：随手记录落进今日日记，`⌘⇧R` 复盘最近几天；`@` 提及页与块，没有同名页时当场建页；
标签有层级，任何块都能配置多个「属于」——拖进左侧归属树是加一条归属关系，不是搬家。

**看**：同一批内容有七种看法——大纲、表格、大纲表格、卡片（画廊/看板）、日历、
思维导图、页签。成员由查询条件决定：条件是一棵可嵌套的条件树，一行读起来就是一句话，
「未填的任务」和「不是任务」这类区别能明确表达。

**属性**：字段全局定义，值写在每块自己身上，在右侧检视卡里编辑。
把一个单选字段标为「任务状态」后，勾选即完成，和内置待办走同一套交互与查询。

**查找**：桌面版全文搜索走 SQLite 全文索引；`⌘P` 命令面板能执行所有命令，
记不住键位也没关系。

## 常用快捷键

| 键 | 做什么 |
|---|---|
| `Enter` / `Tab` | 按落点建块 / 缩进 |
| `⌘⏎` | 切换待办 |
| `⌘B` / `⌘I` / `⌘E` / `` ⌘` `` | 加粗 / 斜体 / 高亮 / 行内代码 |
| `⌘⇧K` / `@` / `#` | 插入引用 / 提及页或块 / 标签 |
| `⌘.` | 折叠 / 展开当前块 |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做 |
| `⌘P` / `⌘K` | 命令面板 / 全文搜索 |
| `⌘T` | 回到今日日记 |
| `⌘⇧L` / `⌘,` | 切换主题 / 设置 |
| `⌘⇧?` | 完整键位表（永远显示当前实际生效的键位） |

鼠标：悬停块左侧出现块标，左键聚焦、右键菜单、拖动重排；
`Shift+点击` 在侧槽开一个窗口，`⌥+点击` 就地查看属性详情。

## 数据放在哪

- **桌面版**：每个库是「文稿/Qua」下的一个目录，内容存在其中的 `qua.db`（SQLite），
  图片按内容哈希存在 `assets/`。每次编辑只写入改动过的部分，库大了也不变慢。
- **浏览器**：数据在浏览器的 localStorage 里，换设备或清理浏览器数据前请先想好备份。
- **删除**：删除是软删，回收站里可以一键恢复。

## 当前限制

- 没有导入导出（Markdown 等格式暂不支持）。
- 桌面版未签名、无自动更新，升级前请备份库目录。
- 跨块拖选部分文字的删除 / 替换还没实现（多选整块操作可以）。
- 行内资产暂时只有图片。
- 没有移动端、协作与插件系统，这些不在近期目标里。

## 参与开发

```bash
pnpm dev            # vite + electron 一起起
pnpm dev:web        # 只起浏览器端 → http://127.0.0.1:5180/
pnpm gate           # 全量门禁：静态断言 + 单测 + 构建 + 冒烟 + 真 Electron
```

需要 Node 26.x 与 pnpm 11.x。动手前请读 [`AGENTS.md`](AGENTS.md)（工程纪律）、
[`CONTRIBUTING.md`](CONTRIBUTING.md)（流程）与 [`docs/ROADMAP.md`](docs/ROADMAP.md)（接下来的计划）。

架构上分五层：`core ← view ← ui ← app ← host`，模型层零 DOM、命令不碰页面元素，
结构约束由 `pnpm arch:check` 静态执行。可视化与更多文档：
[`public/arch.html`](public/arch.html) · [`docs/ARCH-断言.md`](docs/ARCH-断言.md) · [`docs/ELECTRON-备忘.md`](docs/ELECTRON-备忘.md)。
